// HOW XENOXY WORKS

One bot.
Several connected systems.

01

Discord sends an interaction

A member runs a slash command such as /server-health, /birthday or /suggestion.

02

discord.py routes the command

Xenoxy's Python code receives the interaction, checks permissions and runs the matching command function.

03

Per-server settings are loaded

Settings such as welcome channels, suggestion channels, role menus and verification roles are stored by Discord server ID.

04

Xenoxy responds

The bot sends embeds, DMs, buttons, select menus, roles or moderation actions back through Discord.

05

Persistent data is saved

Configuration, birthdays, activity data, reaction roles and backups are stored in xenoxy_data.json so they survive restarts.

06

The bot stays online

The hosted Python process keeps listening for slash commands, reactions, joins, messages and UI button interactions.

// BUILD YOUR OWN DISCORD BOT

Start small.
Then build systems.

01

Create a Discord application

Open the Discord Developer Portal, create an application, add a Bot user and enable only the intents your bot actually needs.

02

Keep the token secret

Put the bot token in a local .env file as DISCORD_TOKEN=.... Never commit the token to GitHub.

03

Install Python packages

Use py -m pip install discord.py python-dotenv.

04

Create bot.py

Load the token, create a Discord client, add a command tree and start with one slash command.

05

Invite and test

Add the bot with the bot and applications.commands scopes, test in your own server and read the terminal errors when something breaks.

06

Add persistence and UI

Once the basics work, add JSON or SQLite storage, embeds, buttons, modals, select menus and permission checks.

MINIMAL BOT.PY
import os
import discord
from discord import app_commands
from dotenv import load_dotenv

load_dotenv()
TOKEN = os.getenv("DISCORD_TOKEN")

class Bot(discord.Client):
    def __init__(self):
        intents = discord.Intents.default()
        super().__init__(intents=intents)
        self.tree = app_commands.CommandTree(self)

    async def setup_hook(self):
        await self.tree.sync()

bot = Bot()

@bot.tree.command(name="ping")
async def ping(interaction):
    await interaction.response.send_message("Pong!")

bot.run(TOKEN)
